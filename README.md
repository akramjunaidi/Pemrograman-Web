# Website Profil & Portal Layanan UKM LDMI Al-Fajr UIN Mataram

Proyek praktikum mata kuliah **Pemrograman Web** (Kelas A7 — Program Studi Teknologi Informasi, UIN Mataram). Website ini dibangun menggunakan **HTML5, CSS3, dan JavaScript (DOM & Web Storage)** dengan tema Unit Kegiatan Mahasiswa **Lembaga Dakwah Mahasiswa Islam (LDMI) Al-Fajr**.

## Struktur Folder Repositori
- `Pengumpulan HTML/` — Kerangka halaman statis HTML murni.
- `Pengumpulan CSS/` — Penerapan styling dasar pada halaman informasi.
- `Pengumpulan HTML+CSS/` — Integrasi tata letak responsif, aset visual, dan data 35 pengurus.
- `Pengumpulan Javascript - Halaman Informasi/` — Manipulasi DOM untuk pencarian pengurus, modal detail, dan katalog kegiatan.
- `Pengumpulan Javascript - Halaman Informasi dan Formulir Dinamis/` — Versi final terintegrasi berisi formulir interaktif, validasi input wajib, dan halaman hasil dinamis berbasis `localStorage`.

## Cara Menjalankan Proyek Secara Lokal
1. Unduh atau *clone* repositori ini, lalu buka folder **`Pengumpulan Javascript - Halaman Informasi dan Formulir Dinamis`** di Visual Studio Code.
2. Jalankan **`organisasi.html`** menggunakan ekstensi **Live Server** (`http://127.0.0.1:5500/organisasi.html`).
